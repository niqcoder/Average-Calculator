# Comprehensive C++ Programming Foundations Suite

A curated collection of foundational software applications built using C++ (Standard ISO/IEC 14882). This repository demonstrates my core competency in algorithms, memory management, compile-time type safety, and terminal-based user interfaces.

##  Included Applications & Technical Highlights

### 1. Terminal-Based Tic-Tac-Toe Game
* **Description:** A classic, interactive 2-player game played entirely within the command-line interface.
* **Concepts Demonstrated:** 2D arrays/matrices for grid rendering, turn-based state machines, game loop control, and automated win/draw condition validation.

### 2. Multi-Unit Conversion Tool
* **Description:** A utility program that seamlessly converts metrics across dimensions like temperature, length, and weight.
* **Concepts Demonstrated:** Mathematical logic mapping, nested if-else structures, using struct, and robust input validation.

### 3. Fixed-Rate Currency Exchange Tool
* **Description:** A localized financial simulator that converts currency metrics based on standard static exchange ratios.
* **Concepts Demonstrated:** Data encapsulation, float/double arithmetic precision, and structured console menus.

### 4. Statistical Average Calculator
* **Description:** A utility designed to process multiple numerical inputs dynamically and compute precise statistical averages.
* **Concepts Demonstrated:** Dynamic array/list handling, iterative accumulators, and edge-case handling (such as preventing division-by-zero errors).

### 5. Multi-Functional Calculator
* **Description:** A clean console application capable of executing primary arithmetic operations based on dynamic user execution inputs.
* **Concepts Demonstrated:** Functional programming, modular code structure, bad input handling and runtime error prevention.
